# RiDoo

This is a simple todo app made for honing my basic html skills. And learning
typescript(which includes but not limited to DOM manipulation, saving and
loading data in local storage, etc.)

## About the Project

This is a **simple** and **beautiful** todo list app for a day to day use. I
made this project following a tutorial as I'm yet to learn how to make it from
scratch. But not all was made by watching the video so I added some of my own
touches and features. Adding todos to the list and saving them and loading them
from Json File in local storage are the only features that I made using
tutorials. Below is a list of all the features in this webapp.

### Features

#### Made using tutorials

- Saving and Loading Tasks from local storage
- Creating a Task and adding it to a list

#### Made by me

- Tasks List and Completed List\
  And moving tasks between both of them depending on their status
- Remove button to remove single task
- a bit about DATEs, still hard to wrap my head around
- Clear All button to remove all tasks from both lists
- Dark theme / Light theme Toggle
- Saving user state of the app on changes
  - saving and loading theme changes
  - saving and loading open or closed states for each list

## What I Used

- Vanilla Typescript
- Html
- CSS

## What I learned

- Types and Interfaces in TypeScript
- Saving and Loading data from local storage using JSON.stringify()
- Using the uuid package to generate unique ids for tasks
- Use CSS over TS/JS whenever possible
- Have good naming conventions when writing codes
